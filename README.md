# Sales_Data_Manipulation
This project focuses on cleaning and analyzing a retail sales dataset to generate meaningful business insights. Using pandas, NumPy, and lambda functions, the project fills missing data, extracts new features, and performs grouped analysis to identify trends and top-performing products.

**Tools & Techniques**:
- Pandas & NumPy for data manipulation

- Lambda functions for group-based imputation (mean and median)

- Feature engineering: Month extraction, total sales computation

- Descriptive statistics: Mean, median, standard deviation

- Product ranking: Top-selling products based on quantity sold

**Key Outcomes**:
- Cleaned dataset with imputed values

- Total monthly sales calculation

- Summary statistics per product

- Identification of top-selling items
